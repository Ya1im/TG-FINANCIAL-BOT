# Решения по проекту «Финансы» (бот + Mini App)

Обновлено: 26.09.2026

## Продукт

- Публичный продукт. Монетизация пока не решена: лимиты и тарифы закладываем в архитектуру, оплату в MVP не делаем.
- Бот отвечает за быстрый ввод (текст, голос, фото чека, выписка), уведомления, дайджесты и алерты.
- Mini App отвечает за дашборд, операции, категории, бюджеты, цели, регулярные платежи и проверку импорта.
- Прогнозы: бюджеты по категориям, регулярные платежи, цели накоплений.
- Аналитика: отчёты в чате с графиками и автодайджесты.

## Этапы

1. **MVP:** текстовый ввод с автокатегориями; Mini App с дашбордом, операциями, категориями и бюджетами; еженедельный дайджест.
2. **v2:** импорт выписок, регулярные платежи, цели.
3. **v3:** голос, чеки, ИИ-советы, оплата.

## Голос

- Распознавание запускается только при получении голосового, в фоновой задаче. Есть лимиты на длину и количество.
- Сервер в РФ, поэтому используем свою модель faster-whisper: бесплатно, данные остаются на сервере.
- Реализация через интерфейс `SpeechToText`; поставщик (своя модель или Groq) выбирается настройкой.
- Распознанный текст разбирает тот же разборщик на правилах, что и обычный текст, без LLM.

## Стек (вариант A)

**Бэкенд:** Python 3.12+, uv, aiogram 3 (webhook), FastAPI, PostgreSQL, SQLAlchemy 2 async + Alembic, Redis, Taskiq, dateparser, openpyxl и pdfplumber, matplotlib. Деньги храним в копейках (int).

**Mini App:** React + TypeScript + Vite, @telegram-apps/sdk-react, @telegram-apps/telegram-ui, TanStack Query, Recharts или ECharts, openapi-typescript.

**Инфраструктура:** Docker Compose (api, worker, postgres, redis, caddy), HTTPS через Caddy.

**Архитектура:** domain / services / ports / adapters / entrypoints (bot, api, worker), чистое ядро.

## Сервер

- Отдельный VPS в РФ (Timeweb Cloud или Selectel), не сервер клиентского бота.
- Для MVP: 2 vCPU / 4 ГБ / 50 ГБ NVMe. С голосом: 4 vCPU / 8 ГБ / 80 ГБ.
- Бэкапы базы в S3, вход по SSH-ключу, файрвол, HTTPS.

## Риски

Подробности в [market-analysis.md](market-analysis.md).

- Telegram в РФ замедлен и частично блокируется (с февраля 2026). До запуска нужно проверить доступ российского сервера к Telegram Bot API.
- Мессенджер должен оставаться заменяемым адаптером, чтобы можно было добавить MAX. Для MAX нужны ИП или юрлицо в РФ.
