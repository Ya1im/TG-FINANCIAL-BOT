# TG-FINANCIAL-BOT

Финансовый помощник в Telegram: бот для быстрого ввода доходов и расходов плюс Mini App с аналитикой, бюджетами, целями и прогнозами.

## Статус

Этап проектирования, кода пока нет.

## Документы

- [Решения по проекту](docs/decisions.md): продукт, этапы, стек, сервер, риски.
- [Анализ ниши](docs/market-analysis.md): спрос, конкуренты, платформенные риски, как выделиться.

## Стек

- **Бэкенд:** Python, aiogram 3, FastAPI, PostgreSQL, Redis, Taskiq.
- **Mini App:** React, TypeScript, Vite.
- **Развёртывание:** Docker Compose на VPS в РФ.
